Games

Add a game server, change its settings, or take it out of service. Nothing is created until you press Enable, and everything is checked against the operator's policy first. View or change the policy.

Enabling games from the dashboard is not configured (managed.dir in config.yaml).

// game modules from a source

Install a module published by someone you trust. It must be signed by one of the keys the operator listed in config.yaml . Installing a module grants it nothing: a game from it still has to fit the policy.

Trusted keys

Listed in config.yaml (managed.trusted_keys); the dashboard cannot change them. To rotate a key, add the new one next to the old, have the publisher sign again, update each module here, then remove the old key from config.yaml.
